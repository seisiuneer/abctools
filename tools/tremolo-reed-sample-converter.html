Tremolo Reed Sample Converter

High-quality two-reed tremolo synthesis from single-note WAV/MP3 reed instrument samples.

Output is mono, 44.1 kHz, IEEE 32-bit floating-point WAV. Samples are sorted from lowest to highest detected pitch. The beat offset is interpolated across that pitch range from the Starting Beat Offset to the Ending Beat Offset. Each note is rendered from two reeds symmetrically detuned around the original pitch; the table shows the resulting cents offset for each reed. A short end fade prevents rate-shift boundary clicks. LUFS normalization is applied only after the two reeds are mixed.

The detected pitch for every file is shown below. If one is wrong, type the correct fundamental frequency in Hz before previewing or converting. This prevents a bad pitch estimate from producing the wrong tremolo detuning.

Processing notes

Pitch detection uses a central, relatively steady part of each sample and normalized autocorrelation. Filename note names such as C4, F#4, Bb3, A_440, etc. are used when they can be identified reliably. You can override every detected frequency. Samples are sorted and processed from low pitch to high pitch; their beat offsets are linearly interpolated by position from the starting Hz value to the ending Hz value. The displayed cents values are calculated from that note's actual fundamental and beat offset. Unlike the first version of this converter, this version does not perform its own linear-interpolation pitch shifting.
