ABC Live Transcriber Instructions

ABC Live Transcriber listens as you play and adds recognized pitches to the ABC area. Click Start Listening, allow microphone access, and play one sustained note at a time. The tool is optimized for notes from G below middle C (G3) through D7.

Set Input gain as needed. The level meter at the upper right shows the incoming signal level.

Your Input gain, Key, Meter, and tin-whistle octave-transposition settings are saved automatically in this browser and restored the next time the tool is opened.

Select the tune Key. The K: field is updated automatically, and detected pitches are written relative to that key signature. For example, in K:D, a detected F-sharp is entered as F, because F-sharp is already part of the D-major key signature. Accidentals outside the key signature use ABC accidentals, with sharp spelling where applicable.

Select the Meter: 2/4, 4/4, 6/8, 9/8, or 12/8. The M:, L:, and Q: header fields update automatically without changing any entered notes. L: is always 1/8. For 2/4 and 4/4, Q: is 1/2=90; for 6/8, 9/8, and 12/8, Q: is 3/8=120.

For tin whistle, enable Transpose detected notes down one octave. Pitch recognition still shows the note actually played, while the ABC output is written one octave lower.

When a note is stable, its ABC note name is appended directly after the previous detected note with no automatic spaces. Duration is not measured; every detected note is entered as a single ABC note token.

The buttons below the ABC area can insert spaces, barlines, repeats, line breaks, duration modifiers, triplets, and grace-note braces at the current insertion point.

Clear ABC restores the standard ABC header using the currently selected key.

You can also edit the ABC manually, copy it, save it as an .abc file, or open it directly in the ABC Transcription Tools.

For best results, use a clean monophonic instrument tone, avoid chords, and leave a small separation between repeated notes of the same pitch.
