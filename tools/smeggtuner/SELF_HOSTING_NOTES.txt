IMPORTANT
This version replaces v1.4.1. Remove stale old files when practical; the
new Nuxt chunk filenames must be deployed with the new HTML. If your hosting
caches HTML or JS aggressively, invalidate it before retesting. Cache keys
are versioned to encourage automatic service-worker upgrades.

The browser WebAudio/microphone and WebAssembly tuning path should be verified
on the live HTTPS site; static tests alone cannot prove audio behavior.
